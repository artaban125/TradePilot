# frontend

React(Vite) 사용자 화면입니다. 담당: **한병준**

| 화면 | 필수 요소 |
| --- | --- |
| 시작 | 서비스 목적, 지원 문서(영문 송장·발주서), 예시 문서 |
| 업로드 | 파일 선택·드래그, 형식·용량 안내 |
| 처리 중 | 단계 표시 (문서 읽는 중 → 검산 중 → 해설 작성 중) |
| 결과 | 원문 이미지 ↔ 한글 거래정보 표 · 쉬운 해설 · 부서별 체크리스트 |
| 확인 필요 | 검산 불일치·누락 경고 배너, 해당 칸 강조 |
| 오류 | 판독 불가·시간 초과 안내, 재시도 |

백엔드 주소는 `.env`의 `VITE_API_BASE_URL`로 설정합니다. 백엔드가 준비되기 전에는 목업 JSON으로 개발합니다.
